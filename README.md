# GNB Labs — skills gratis para Claude Code

Siete plugins de Claude Code en español de México, licencia MIT. Se instalan en dos comandos
y funcionan tal cual: el bloque `[CUSTOMIZE]` está para cambiarles la marca, no para que
arranquen.

## Instalación

```bash
claude plugin marketplace add gneuman/gnb-plugins
claude plugin install gnb-explicame@gnb-labs
```

## Los siete

| Plugin | Comando | Qué hace |
| -- | -- | -- |
| `gnb-explicame` | `/explicame` | La duda se vuelve la pieza visual más chica que la resuelve |
| `gnb-design-system` | `/gnb-design-system` | Genera tu página de componentes dentro de la app |
| `gnb-idea-to-prd` | `/idea-to-prd` | Entrevista de 10 fases que convierte una idea en spec |
| `gnb-prd-to-issues` | `/prd-to-issues` | Parte el PRD en tickets que alguien sí toma |
| `gnb-call-to-content` | `/call-to-content` | Una grabación se vuelve diez días de contenido |
| `gnb-call-to-voc` | `/call-to-voc` | Saca el lenguaje literal del cliente de un discovery |
| `gnb-podcast-guesting` | `/pg-setup` | Seis skills para conseguir apariciones en podcasts |

Cada uno tiene su ficha con el método completo en
[gabrielneuman.com/sistemas/skills/](https://gabrielneuman.com/sistemas/skills/explicame/).
